Изменения в проекте

1. Ручная загрузка сертификатов

Добавлена поддержка загрузки сертификатов вручную для обеспечения HTTPS.

Сертификаты необходимо загрузить в конфигурацию сервера (например, для NGINX или другого веб-сервера).

Пример конфигурации (NGINX):

server {
listen 443 ssl;
server_name yourdomain.com;

ssl_certificate /path/to/certificate.crt;
ssl_certificate_key /path/to/private.key;
}

2. Закрытие портов, кроме 443 и TCP

Оставлены открытыми только порты 443 (HTTPS) и необходимые порты для работы TCP.

Остальные порты были закрыты с целью повышения безопасности.

3. Добавление новых пользователей с разграничением прав

Добавлена функциональность для добавления новых пользователей и настройки их ролей.

Роли:

admin - полный доступ.

user - ограниченный доступ.

Эндпоинт для добавления нового пользователя:

POST /api/users — для создания нового пользователя.

Пример запроса:

{
"username": "new_user",
"password": "password123",
"role": "user"
}

4. Все порты переделаны на внутренние (127.0.0.1:xxxx)

Все порты, ранее доступные извне, были изменены на внутренние порты.

Использование локального хоста (127.0.0.1) предотвращает их сканирование извне и повышает безопасность.

5. Отправка RS команд через Web интерфейс

Внедрена возможность отправки команд RS через веб-интерфейс.

Эндпоинт для отправки RS команд:

POST /api/rs232/command — отправка команды RS232.

Пример запроса:

{
"command": "your_command_here"
}
